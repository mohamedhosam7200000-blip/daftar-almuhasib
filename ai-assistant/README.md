# خبير — مساعد ذكي متعدّد التخصّصات

مساعدٌ بالذكاء الاصطناعي يعمل كـ **محاسب قانوني، ومدير مالي، ومدير إداري،
ومهندس (مدني وبرمجيات)، ومصمّم مواقع** في آنٍ واحد. مبنيٌّ على نموذج Claude
من Anthropic، مع أدوات حسابٍ دقيقة حتى لا يخطئ في الأرقام.

## لماذا ليس «نموذجاً مدرَّباً من الصفر»؟

تدريب نموذج لغويّ قويّ من الصفر يكلّف ملايين الدولارات وآلاف المعالجات
وشهوراً من العمل، ولن يتفوّق على النماذج الحالية. الطريق العمليّ والأقوى هو:

1. **أقوى نموذج متاح** كعقلٍ مفكّر (`claude-opus-5-5` مع التفكير التكيّفي).
2. **تعليمات خبير** تحدّد التخصّصات وأسلوب العمل ([`khabeer/prompts.py`](khabeer/prompts.py)).
3. **أدوات حساب حتمية** يستدعيها النموذج بدلاً من الحساب الذهني ([`khabeer/calc.py`](khabeer/calc.py)).

## الأدوات المتاحة للنموذج

| الأداة | الاستخدام |
|---|---|
| `calculate_vat` | فصل الصافي والضريبة والإجمالي (شاملة أو غير شاملة) |
| `depreciation_schedule` | جدول إهلاك: قسط ثابت، متناقص مضاعف، مجموع السنوات |
| `loan_amortization` | جدول سداد قرض بأقساط شهرية متساوية |
| `investment_appraisal` | دراسة جدوى: صافي القيمة الحالية، معدّل العائد الداخلي، فترة الاسترداد |
| `break_even` | نقطة التعادل بالوحدات والإيراد، أو لربحٍ مستهدف |
| `financial_ratios` | نسب السيولة والمديونية والربحية والكفاءة ودورة التحويل النقدي |
| `check_journal_entry` | التحقّق من توازن القيد المحاسبي وصحّة سطوره |
| `concrete_quantity` | حصر كمّيات الخرسانة وتكلفتها مع نسبة الهالك |
| `save_file` | حفظ صفحات الويب والتقارير والشيفرة في مجلّد `output/` |

## نسخة الويب (Netlify)

في مجلد [`web/`](web/) نسخة تعمل في المتصفّح بالأدوات نفسها، بواجهة محادثة عربية
ومعاينة وتنزيل للملفّات التي يصمّمها. كلّ مستخدم يُدخل مفتاح API الخاصّ به في
الإعدادات، فيُحفظ في متصفّحه ولا يمرّ بأيّ خادمٍ غير خوادم Anthropic.

```bash
cd ai-assistant/web
npm install
npm run build     # ينتج مجلّد dist/ — موقعٌ جاهز
npm test
```

**الرفع**: اسحب مجلّد `dist/` وأفلته في <https://app.netlify.com/drop>.
أو اربط Netlify بالمستودع واجعل Base directory = `ai-assistant/web`
(الإعدادات في `netlify.toml`).

## التشغيل من الطرفية

```bash
cd ai-assistant
pip install -r requirements.txt
export ANTHROPIC_API_KEY="sk-ant-..."     # من console.anthropic.com
python -m khabeer
```

على ويندوز (PowerShell): `$env:ANTHROPIC_API_KEY="sk-ant-..."`

### أمثلة

```
أنت › اشتريت سيارة بـ 120,000 وعمرها 5 سنوات وخردتها 20,000، اعمل جدول إهلاك بالقسط المتناقص وقيد السنة الأولى
أنت › عندي مطعم تكاليفه الثابتة 45,000 شهرياً ومتوسط الفاتورة 85 وتكلفتها 32، كم فاتورة أحتاج لأربح 30,000؟
أنت › صمّم صفحة هبوط عربية لمكتب محاسبة اسمه «الأمانة» فيها الخدمات والأسعار ونموذج تواصل
أنت › احسب خرسانة 12 قاعدة مقاس 1.8×1.8×0.6 م وسعر المتر 280
```

## الإعدادات (متغيّرات البيئة)

| المتغيّر | الافتراضي | الوصف |
|---|---|---|
| `KHABEER_MODEL` | `claude-opus-5-5` | النموذج المستخدم |
| `KHABEER_EFFORT` | `high` | عمق التفكير: `low` / `medium` / `high` / `xhigh` / `max` |
| `KHABEER_OUTPUT_DIR` | `output` | مجلّد حفظ الملفّات |

عند رفض طلبٍ لأسباب السلامة يعيد الخادم المحاولة تلقائياً على نموذجٍ بديل
مناسب (`fallbacks: "default"`).

## التوسعة

- **أداة جديدة**: أضف دالّة في `calc.py` واختباراً لها، ثم غلافاً بـ `@beta_tool`
  في `tools.py` وأضفه إلى `ALL_TOOLS`.
- **تخصّص جديد أو قوانين دولةٍ بعينها**: أضفها إلى `SYSTEM_PROMPT`.

> تنبيه: النسب الضريبية والقوانين تختلف بين الدول وتتغيّر. المساعد يصرّح
> بافتراضاته، لكن القرارات الضريبية والقانونية الملزمة تحتاج مراجعة محاسبٍ
> قانونيّ مرخّص.
