# موقع M7 RAQM للاستشارات المالية

موقع شركة كامل ومستجيب، عربي/إنجليزي (RTL + LTR)، بتصميم مودرن مينيماليست،
مع نموذج حجز استشارات متصل بـ **Stripe Checkout** لاستلام الدفعات.

وهو أيضاً **تطبيق قابل للتثبيت** (PWA) على الجوال والتاب والآيفون وسطح المكتب،
يعمل دون إنترنت — انظر القسم ٧٫٥.

مبني بـ HTML/CSS/JavaScript خام — **بدون أي أدوات بناء أو تثبيت**.
يكفي فتح `index.html` في المتصفح لرؤية الموقع كاملاً
(ميزات التطبيق تحتاج HTTPS، أي بعد النشر).

## 4.5 الخدمة المميزة: منصة قوائم

الموقع يقدّم خدمة واحدة كواجهة رئيسية للتسويق، ويعرضها في أربعة مواضع:

| الموضع | الملف |
|---|---|
| شارة الواجهة الرئيسية | `i18n.js` → `home.hero.badge.text` |
| قسم بارز أسفل شريط الثقة | `index.html` → `<section>` بـ `.spotlight` |
| أول خدمة في صفحة الخدمات | `services.html` → `#srv-9` بـ `.srv--featured` |
| أول ٣ أسئلة شائعة | `services.html` → `faq-7` و `faq-8` و `faq-9` |
| خيار في نموذج الحجز | `booking.html` → `opt.topic.qawaem` |

**رسالة الخدمة:** المنشآت الصغيرة والمتوسطة التي ليس لديها مراجع خارجي معيّن
تبقى قوائمها غير مدققة ويتعثّر رفعها على منصة قوائم. المكتب يُجهّز القوائم
بمراجعة فعلية للدفاتر — مطابقة كل رصيد بمستنده المؤيد — **لا بتصدير آلي من
النظام المحاسبي**، ثم يرفعها نيابةً عن العميل.

نقطة التمايز في كل النصوص هي التقابل بين *العمل المحاسبي الفعلي* و*المخرجات
الآلية*، وهي مركز السؤال الشائع الثاني (`faq.8`).

كل نصوص هذه الخدمة تبدأ بالمفتاح `qawaem.*` و `srv.9.*` في `i18n.js`.

> **قبل النشر — راجع هذه النقطة مع مستشارك النظامي:** إصدار تقرير مراجعة
> يتطلب ترخيص مكتب مراجعة من الهيئة السعودية للمراجعين والمحاسبين. الصياغة
> الحالية تركّز على *الإعداد والمطابقة والرفع*، لكن كلمة "تدقيق" ترد في نصوص
> الخدمة. إن لم يكن الترخيص باسم المكتب، عدّل الصياغة إلى "إعداد ومطابقة
> القوائم" وأزل ما يوحي بإصدار تقرير مراجع.

## 6. الأسعار والباقات

الأسعار معرّفة في **مكانين، ويجب أن يتطابقا**:

1. `assets/js/config.js` → مصفوفة `packages` (يُحسب منها ملخص الطلب في المتصفح).
2. `api/create-checkout-session.js` → ثابت `PACKAGES` (**هو المرجع للمبلغ المخصوم فعلياً**).

الفصل مقصود لسبب أمني: الخادم لا يثق بأي سعر يرسله المتصفح، بل يقرأ السعر من
جدوله الخاص. لو عدّلت ملف الواجهة وحده، سيظهر السعر الجديد لكن الخصم سيتم بالسعر القديم.

الأسعار الحالية (قبل الضريبة):

| المعرّف | الباقة | السعر | النوع |
|---|---|---|---|
| `quick` | استشارة سريعة (٤٥ د) | 450 ر.س | دفعة واحدة |
| `extended` | استشارة موسّعة (٩٠ د) | 950 ر.س | دفعة واحدة |
| `retainer` | المرافقة الشهرية | 2,900 ر.س | اشتراك شهري |

تُضاف ضريبة القيمة المضافة ١٥٪ تلقائياً على المبلغ المخصوم
(`VAT_RATE` في ملف الخادم، و `vatRate` في `config.js`).

كما تظهر نصوص الباقات (الاسم، الوصف، المميزات) في `i18n.js` تحت `plan.1.*` و `plan.2.*` و `plan.3.*`،
وفي بطاقات الأسعار داخل `index.html` و `booking.html`.

## 7. تفعيل الدفع عبر Stripe

الموقع الآن في **وضع المعاينة**: النموذج يعمل ويتحقق من البيانات، لكنه لا يتصل بـ Stripe.

### الخطوة ١ — حساب Stripe
أنشئ حساباً على [stripe.com](https://stripe.com) وفعّل الحساب للمملكة العربية السعودية
حتى تتمكن من استقبال الريال السعودي (SAR) وبطاقات مدى.

### الخطوة ٢ — انسخ المفاتيح
من لوحة Stripe: **Developers → API keys**.
ابدأ بمفاتيح الاختبار (`sk_test_...`) للتجربة.

### الخطوة ٣ — انشر الموقع
انظر القسم ٨ أدناه. أثناء النشر أضف متغيرات البيئة:

```
STRIPE_SECRET_KEY=sk_test_xxxxx
SITE_URL=https://نطاقك.com
```

### الخطوة ٤ — اضبط الـ Webhook
من لوحة Stripe: **Developers → Webhooks → Add endpoint**

- **URL:** `https://نطاقك.com/api/stripe-webhook`
- **Events:** `checkout.session.completed` و `invoice.paid` و `checkout.session.expired`

انسخ الـ **Signing secret** وأضفه كمتغير بيئة:

```
STRIPE_WEBHOOK_SECRET=whsec_xxxxx
```

### الخطوة ٥ — فعّل الدفع في الموقع
في `assets/js/config.js` غيّر:

```js
stripe: {
  endpoint: '/api/create-checkout-session',
  enabled: true          // ← كانت false
}
```

### الخطوة ٦ — اختبر
استخدم بطاقة Stripe التجريبية: `4242 4242 4242 4242`، أي تاريخ مستقبلي، وأي CVC.
تأكد من وصولك إلى `success.html` ومن ظهور العملية في لوحة Stripe.

### الخطوة ٧ — الانتقال للوضع الحي
بدّل المفاتيح إلى `sk_live_...` وأعد ضبط الـ webhook على الوضع الحي.

### ماذا يحدث بعد الدفع؟
`api/stripe-webhook.js` يستقبل الإشعار ويطبع بيانات الحجز في السجل.
**هنا تضيف منطقك الخاص** (مكان `TODO` في الملف): حفظ الحجز في قاعدة بيانات،
إرسال بريد تأكيد، أو إنشاء موعد في التقويم.
كل بيانات النموذج متاحة في `session.metadata`.

## 7.5 التطبيق على الجوال والتاب والآيفون (PWA)

الموقع **هو** التطبيق. لا يوجد كود منفصل ولا نسخة ثانية تحتاج صيانة —
أي تعديل على الموقع يصل للمستخدمين المثبّتين تلقائياً.

### ماذا يحصل للمستخدم

| الجهاز | كيف يثبّته | النتيجة |
|---|---|---|
| Android | يظهر شريط «ثبّت تطبيق M7 RAQM» تلقائياً، أو زر «حمّل التطبيق» في القائمة | أيقونة على الشاشة الرئيسية، يفتح بلا شريط متصفح |
| iPhone / iPad | Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية» (الموقع يعرض التعليمات مصوّرة تلقائياً) | نفس النتيجة |
| Windows / Mac | أيقونة التثبيت في شريط عنوان Chrome أو Edge | تطبيق سطح مكتب بنافذة مستقلة |

بعد التثبيت: يعمل **دون إنترنت** (الصفحات المزارة محفوظة)، يفتح بشاشة كاملة
بلون الهوية، وله اختصارات ضغط مطوّل: **حجز · قوائم · الخدمات**.

### الملفات

```
manifest.webmanifest        ← اسم التطبيق وأيقوناته واختصاراته
sw.js                       ← Service Worker: التخزين والعمل دون إنترنت
offline.html                ← الصفحة البديلة عند انقطاع الاتصال
assets/js/pwa.js            ← التسجيل، دعوة التثبيت، إشعار التحديث
assets/img/app/             ← أيقونات PNG مولّدة من هندسة اللوغو
    icon-192.png · icon-512.png
    icon-maskable-192.png · icon-maskable-512.png   (لأندرويد)
    apple-touch-icon.png                            (لـ iOS)
    favicon-32.png
```

### شرطان لعمل التطبيق

1. **HTTPS إلزامي.** لن يُسجَّل Service Worker عبر `file://`. فتح `index.html`
   بالنقر المزدوج يعرض الموقع لكن دون ميزات التطبيق. بعد النشر على Vercel أو
   Netlify يعمل تلقائياً لأنهما يوفّران HTTPS. للتجربة محلياً استخدم
   `http://localhost`.
2. **ارفع رقم الإصدار عند كل تحديث.** في أعلى `sw.js`:
   ```js
   const VERSION = 'v1.0.0';   // ← غيّره إلى v1.0.1 ... بعد أي تعديل
   ```
   بدون ذلك سيبقى المستخدمون على النسخة المحفوظة. عند رفع الرقم يظهر لهم
   إشعار «يتوفّر تحديث للتطبيق» بزر تحديث.

### ما لا يُخزَّن عمداً

مسار `/api/` مستثنى من التخزين بالكامل، لأن إنشاء جلسة الدفع يجب أن يمر
بالشبكة الحيّة دائماً. أي طلب غير `GET` يمر مباشرة دون تدخّل.

### إن أردت التطبيق في App Store و Google Play

الـ PWA يُثبَّت من المتصفح لا من المتجر. الوجود في المتجر خطوة منفصلة تبني
على نفس هذه الملفات ولا تلغيها:

| المتطلب | Google Play | App Store |
|---|---|---|
| الأداة | [PWABuilder](https://www.pwabuilder.com) أو Bubblewrap (TWA) | [PWABuilder](https://www.pwabuilder.com) أو Capacitor |
| البيئة | Node.js + Android Studio | Node.js + **جهاز Mac** + Xcode |
| حساب المطوّر | ‏٢٥ $ مرة واحدة | ‏٩٩ $ سنوياً |
| المراجعة | أيام | أيام إلى أسابيع |

أسرع طريق: ارفع الموقع على HTTPS، ثم أدخل رابطه في PWABuilder وسيولّد لك
حزمة Android جاهزة للرفع. حزمة iOS تحتاج جهاز Mac لتوقيعها.

> ملاحظة: Apple ترفض أحياناً التطبيقات التي هي مجرد غلاف لموقع دون قيمة
> إضافية. إن استهدفت App Store، يُنصح بإضافة ميزة أصيلة للجوال — إشعارات
> للمواعيد، أو رفع مستندات بالكاميرا مثلاً.

## 8. النشر

### Vercel (الأسهل)

```bash
npm install -g vercel
vercel
```

ثم من لوحة Vercel: **Settings → Environment Variables** أضف
`STRIPE_SECRET_KEY` و `STRIPE_WEBHOOK_SECRET` و `SITE_URL`.

### Netlify

اربط المستودع أو اسحب المجلد إلى Netlify. ملف `netlify.toml` يوجّه `/api/*`
إلى الدوال تلقائياً. أضف متغيرات البيئة نفسها من **Site settings → Environment variables**.

### استضافة عادية (بدون دوال خادم)

الصفحات الست تعمل على أي استضافة ثابتة، لكن **الدفع لن يعمل** لأنه يحتاج خادماً
لحفظ المفتاح السري. البديل في هذه الحالة: أنشئ
[Stripe Payment Links](https://stripe.com/payments/payment-links) لكل باقة،
واستبدل زر الدفع برابط مباشر.

## 10. ملاحظات تقنية

- **تعدد اللغات:** يعمل بتبديل `lang` و `dir` على وسم `<html>` وتعبئة النصوص من
  القاموس. التصميم يستخدم خصائص CSS المنطقية (`margin-inline`, `inset-inline`)
  فينقلب الاتجاه كاملاً دون أي كود إضافي. اللغة تُحفظ في `localStorage`،
  ويمكن فرضها برابط مثل `?lang=en`.
- **الاستجابة:** نقاط التوقف عند 1000px و 980px و 940px (القائمة) و 640px.
  مختبر من 375px حتى 1280px دون أي تمرير أفقي.
- **الوصولية:** روابط تخطٍّ، `aria-expanded` على القائمة والأكورديون،
  رسائل خطأ مرتبطة بالحقول، واحترام `prefers-reduced-motion`.
- **الأمان:** المفتاح السري لـ Stripe لا يظهر في المتصفح إطلاقاً. الأسعار تُحسم
  من الخادم. توقيع الـ webhook يُتحقق منه قبل أي معالجة.
